# UCSC Catalog Expansion Lab

This folder is a staging/QA holder for expanding the Prototype 5.1 course database before any generated records are merged into `js/courses.js`.

## Purpose

- Scrape/index the official UCSC General Catalog course pages separately from the production scheduler data.
- Preserve raw official evidence for every candidate course.
- Convert official data into the same JSON-shaped course-record format used by `COURSES`.
- Run quality gates before merging new courses into the app.

## Source of truth

Use only current official UCSC General Catalog course pages:

- Course index root: `https://catalog.ucsc.edu/en/current/general-catalog/courses`
- Individual course pages under `/en/current/general-catalog/courses/<department>/<division>/<course-code>`

Do not use guessed URLs, third-party catalogs, old archived catalog pages, or LLM-filled course metadata as source of truth.

## Proposed files

Generated/audit files should live here first:

- `official-catalog-live-index.json` — latest crawl of departments and course links.
- `local-vs-official-coverage-report.json` — comparison between live official catalog and current `js/courses.js`.
- `missing-courses-by-department.json` — exact official courses absent from local DB.
- `official-course-raw-pages/` — optional raw HTML snapshots for reproducibility/debugging.
- `official-course-details.json` — parsed title, units, description, GE, prerequisites, enrollment restrictions, and official URL.
- `candidate-expanded-courses.json` — normalized candidate records in the existing `COURSES` schema shape.
- `qa-report.md` — human-readable extraction quality report and merge readiness notes.

## Merge rule

Nothing from this folder should be merged into `js/courses.js` until it passes the QA gates documented in `SCRAPING_AND_QA_PLAN.md`.
